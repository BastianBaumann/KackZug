# Symbole

Die Symbole stammen aus dem KackZug-Designsystem: Outline, 24 × 24, Strich 2 px, runde Enden.
`plus.svg` und `trash.svg` sind im selben Stil ergänzt, weil das Designsystem dafür noch kein Symbol hat.
`tools/design/build_assets.py` macht daraus die Avalonia-Geometrien in `src/KackZug.App/Themes/Icons.axaml`.
